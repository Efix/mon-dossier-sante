# Contribuer

Merci de l'intérêt que tu portes à Mon dossier santé. Le projet est maintenu par une seule personne : cette page explique ce qui aide le plus, et ce qui n'est pas possible pour l'instant.

## Ce qui est bienvenu

- **Signaler un problème** : une erreur, un comportement inattendu, un résultat mal lu. Utilise le modèle « Signaler un problème » dans les [tickets](https://github.com/Efix/mon-dossier-sante/issues/new/choose).
- **Proposer une amélioration** : une fonction qui te manque, une formulation peu claire. Utilise le modèle « Proposer une idée ».
- **Demander la prise en charge d'un laboratoire** dont les comptes rendus ne sont pas lus automatiquement. Utilise le modèle prévu à cet effet.
- **Signaler une faille de sécurité** : jamais dans un ticket public. Suis la [politique de sécurité](SECURITY.md).
- **Signaler une difficulté d'accessibilité** : voir la [déclaration d'accessibilité](ACCESSIBILITY.md).

## Tes données de santé

Les tickets sont publics et le restent. **N'y joins jamais** un vrai compte rendu, un coffre `.sante`, une phrase secrète, ni une capture d'écran où apparaissent un nom, une date de naissance, un numéro de sécurité sociale ou des résultats qui te concernent.

Pour un document mal lu, décris sa mise en page (titres, colonnes, ordre des informations), ou fournis un exemple dont tu as remplacé toutes les informations personnelles et tous les résultats par des valeurs inventées.

## Contributions de code

Le code est public pour pouvoir être lu et vérifié, mais il n'est pas sous licence libre : voir [LICENSE](LICENSE). **Les demandes de fusion (pull requests) ne sont pas acceptées pour l'instant.** Un correctif qui te semble utile peut être décrit dans un ticket ; s'il est retenu, il sera intégré par le mainteneur.

Si tu veux comprendre le fonctionnement du code, l'organisation des sources, la construction de l'application, les tests et la publication des versions sont décrits dans [DEVELOPPEMENT.md](DEVELOPPEMENT.md).

## Délais

Le projet est développé sur du temps libre. Chaque ticket est lu, mais une réponse peut prendre plusieurs jours. Un ticket clair, avec la version de l'application (indiquée sur l'écran d'accueil et dans la page Coffre) et le navigateur utilisé, est traité plus vite.

## Comportement

Les échanges sur ce dépôt suivent le [code de conduite](CODE_OF_CONDUCT.md).
